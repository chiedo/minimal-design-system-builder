What is Minimal Design System Builder?

Minimal Design System Builder is a free design tool that runs as one HTML file in the browser. You set a color palette, type roles, button sizes, and spacing, check them on a live preview, and download CSS custom properties. Nothing is installed and nothing is uploaded.

What can you design?

  • Color palette. Primary, neutral, accent, danger, warning, and success. Set hue, saturation, lightness, the light and dark edges, optional hue rotation, and a manual HSL value for any shade.
  • Type roles. Display, UI, and mono families, plus a role for H1 through H6, body, UI, caption, and mono. Each role has a font, weight, size step, line height, tracking, and ink color.
  • Buttons. Small, medium, and large. Each size has its own type step, vertical padding, horizontal padding, and icon size. Hierarchy is primary, secondary, tertiary, and danger. Inputs share the selected control height.
  • Space. A spacing scale, roundness for boxes and the nav header, a separate button radius, five shadow elevations, border widths, a focus ring, icon sizes, opacity, and max-widths.
  • Preview. An app screen, a color board, a type specimen, and a component sheet. Dark preview exports as a data-theme="dark" block in the CSS.

How do you export CSS tokens?

  1. Open Minimal Design System Builder in Chrome, Edge, or Firefox. There is no install.
  2. Set the palette, type roles, button sizes, and spacing. The preview updates as you edit.
  3. Choose Download CSS, or open Export and copy CSS or JSON.
  4. Paste tokens.css at the top of your stylesheet and use the custom properties.

Questions

Does Minimal Design System Builder need an install or an account?

No. Open the page in Chrome, Edge, or Firefox. There is no account. Edits stay in this browser's local storage, and an imported palette file stays on your computer.

What can I design with it?

A six-scale color palette, type roles for H1 through H6 plus body, UI, caption, and mono, three button sizes, and spacing, radius, shadow, border, focus, icon, and opacity tokens.

How do I export CSS tokens?

Adjust the tokens, then choose Download CSS or open Export and copy CSS or JSON. Paste tokens.css at the top of your stylesheet and use the custom properties, including a dark theme under [data-theme=dark].

Can I import an existing color palette?

Yes. Import JSON reads a palette file in the browser, including palette-XX.json from the Refactoring UI Color Palettes ZIP. The file is not uploaded.

Is Minimal Design System Builder free?

Yes. The builder and the source code are free to use. The source is on GitHub.
